# Contribuir a Simple Launcher

1. Abre un issue para cambios grandes o nuevas funciones.
2. Mantén separados los cambios de lógica, interfaz y recursos.
3. No borres datos del usuario sin confirmación explícita y una ruta de backup.
4. Documenta cualquier cambio que afecte instalaciones, perfiles, mods o backups.
5. Para cambios visuales, incluye capturas antes y después.

Comprueba la sintaxis antes de enviar cambios:

```powershell
python -m py_compile source/launcher_theme.py
```
