# Contributing to Simple Launcher

1. Open an issue for major changes or new features.
2. Keep logic, UI, and resource changes separate when possible.
3. Do not delete user data without explicit confirmation and a backup path.
4. Document any change that affects installations, profiles, mods, or backups.
5. Include before-and-after screenshots for visual changes.

Check the syntax before submitting changes:

```powershell
python -m py_compile source/launcher_theme.py
```
